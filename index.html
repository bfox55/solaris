Orrery Bench

We give different AI models the exact same one-line prompt and publish what each one builds. Since the prompt never changes, the differences between these simulations come from the models themselves.

For maintainers: adding a run

Put the build in its own directory, then add one object to ENTRIES at the top of this file. Everything on the page renders from that list, so nothing else needs editing.
