# Texture attribution

Planet textures by [Solar System Scope / INOVE](https://www.solarsystemscope.com/textures/), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Downloaded September 10, 2026. Assets are unmodified.

The linked source page identifies the projection as equirectangular and permits use, adaptation, and sharing including commercial use under CC BY 4.0.

The maps derive from NASA elevation and imagery. Unmapped areas may contain fictional terrain; colors are slightly saturated. These are illustrative textures, not current observational data. Saturn ring is a 2048 x 125 strip for radial mapping. Earth clouds is an RGB map suitable for using luminance as opacity.
